# DEPRECATED

**ai-framework is superseded by [Viterbi](https://github.com/Dario-Arcos/Viterbi)** — an agnostic meta-harness for agentic engineering (Claude Code, Codex, and more).

- Plugins marketplace: [Dario-Arcos/plugins](https://github.com/Dario-Arcos/plugins)
- Direct add (Claude Code): `/plugin marketplace add Dario-Arcos/Viterbi`
- Direct add (Codex): `codex plugin marketplace add Dario-Arcos/Viterbi`

Existing local installs of the ai-framework plugin keep working from cache, but this repository receives no further updates and cannot be reinstalled from scratch.
